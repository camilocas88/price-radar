# T-019 — Componentes de UI y búsqueda sincronizada por URL

- Feature: F-015
- Dueño: Claude
- Rama: `feature/t-019-search-url-components`
- Estado: `claiming` → `in_progress` tras publicar draft PR.

## Objetivo

`src/app/page.tsx` es hoy un componente monolítico con toda la UI, el estado y el fetch. Se separa en piezas por responsabilidad y se conecta el término de búsqueda al `?query=` para que la búsqueda sea compartible y navegable con back/forward.

## Alcance

- Extraer `Nav`, `Hero`, `SearchForm`, `StatusStrip`, `ResultsSection`, `OfferCard`, `SkeletonList` y `HomeExperience` a `src/app/components/`.
- Encapsular estado, fetch y sincronización con `useSearchParams`/`useRouter` en `src/app/hooks/useOfferSearch.ts`.
- Auto-disparar la búsqueda cuando la URL entra con `?query=…`; escribir con `router.replace` para no llenar el history.
- `page.tsx` queda como Server Component que envuelve `<HomeExperience />` en `<Suspense>` (requisito de Next 16 para `useSearchParams`).
- Añadir skeleton visible mientras `status === "loading"`.
