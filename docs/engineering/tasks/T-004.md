- Objetivo: verificar el acceso de búsqueda de Mercado Libre Colombia y diferenciar una fuente bloqueada de una búsqueda válida sin ofertas, sin mostrar demo como resultado real.

## Contrato previo a cambios compartidos

`GET /api/offers?query=<texto>` conserva el éxito `{ offers: Offer[], source: "mercadolibre" }` con HTTP 200. `offers: []` significa que la fuente respondió correctamente y no devolvió ofertas normalizables. Si la fuente rechaza la consulta, la ruta devuelve HTTP 503 y `{ error: string, code: "SOURCE_FORBIDDEN" | "SOURCE_RATE_LIMITED", source: "mercadolibre" }`. Otros errores de upstream, formato o red devuelven HTTP 502 con `code: "SOURCE_UNAVAILABLE"`. La UI trata esas respuestas no exitosas como indisponibilidad; nunca sustituye un fallo de fuente por una lista vacía ni por ofertas demo etiquetadas como reales.

El contrato de `Offer` y el normalizador no cambian. Solo se utiliza el endpoint oficial; no hay scraping, login automatizado ni credenciales nuevas en Git. Alternativa autorizada futura: enlaces aportados por usuarios (F-008) y APIs/feeds con permiso expreso; no se afirma que esas fuentes ya estén operativas.

## Aceptación

- Queda evidencia reproducible, sin secretos, del estado HTTP y cuerpo de error de la API oficial.
- HTTP 200 vacío, 403, 429 y fallos de red se distinguen en pruebas de la ruta.
- La UI comunica la indisponibilidad de la fuente y no presenta la demo como respuesta de la búsqueda fallida.
- El ticket documenta el estado real y la vía autorizada de continuación. `README.md` no se modifica porque F-003 aún figura como dueño en el registro aunque su PR ya fue fusionada.
- `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` y `npm run features:check` pasan; otro agente revisa antes de marcar `done`.
