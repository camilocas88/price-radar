# T-002 — Búsqueda autorizada de Mercado Libre

- Dueño: Codex
- Estado: en curso
- Módulos permitidos: `src/app/api/offers`, `src/lib/mercadolibre.ts`, `src/lib/offers.ts`, `src/lib/*.test.ts`, `src/app/page.tsx`, README, manifiestos de dependencias y CI.
- Objetivo: exponer ofertas de Colombia mediante el recurso público oficial `GET /sites/MCO/search?q=…` de Mercado Libre, sin scraping ni credenciales.

## Contrato

`GET /api/offers?query=<texto>` devuelve `{ offers: Offer[], source: "mercadolibre" }`. Cada `Offer` contiene precio en COP, envío solo cuando la API lo confirma como gratuito, URL canónica de la publicación, disponibilidad referencial y los indicadores de confianza derivados de campos públicos. La API nunca afirma impuestos, inventario exacto ni garantía si Mercado Libre no los entrega.

## Aceptación

- Consulta a `api.mercadolibre.com/sites/MCO/search` con límite acotado y URL codificada.
- Respuesta normalizada y validada sin depender de HTML ni automatizar login.
- UI permite buscar y muestra estados de carga, error y resultados reales con enlace a la oferta.
- Pruebas unitarias cubren la normalización y manejo de campos ausentes.
- Gates completos y handoff documentado antes de cerrar.

## Evidencia

- `npm run lint`: correcto.
- `npm run typecheck`: correcto.
- `npm test`: correcto (5 pruebas en 2 archivos).
- `npm run build`: correcto; incluye la ruta dinámica `/api/offers`.
- `npm ci`: correcto en una instalación limpia con Node 22; se actualizó `@types/node` a la serie 22 para resolver el conflicto de peer dependencies de `vitest@5` que rompía GitHub Actions.
- CI: se regeneró el lockfile y se fijó `picomatch` 4 mediante `overrides`, porque el lock anterior resolvía una versión 2 incompatible con `fdir` en el runner de GitHub.
- Consulta manual al endpoint oficial `GET /sites/MCO/search`: el entorno recibió `403`. La ruta soporta `MERCADOLIBRE_ACCESS_TOKEN` para una aplicación autorizada; falta validar con ese acceso antes de producción.
- Riesgo: no se debe marcar Mercado Libre como fuente disponible en producción sin un token autorizado y una prueba de respuesta real.
- Siguiente paso: obtener/autorizar la aplicación de Mercado Libre, configurar el secreto en el entorno de despliegue y ejecutar una prueba de humo contra `/api/offers`.
- Handoff: crear PR al terminar el ticket; solo el humano propietario puede fusionarla a `main`.
