# T-030 — Compatibilidad de región en Brave Search

- Dueño: Codex
- Estado: `claiming`

- PR: pendiente

## Objetivo y contrato

El smoke real con la clave local confirmó HTTP 422 (`VALIDATION`) al solicitar `country=CO`, y HTTP 200 con resultados de Éxito al omitir ese parámetro. El adaptador dejará de enviar `country`, mantendrá `search_lang=es` y la palabra «Colombia» en `q`. No se cambia el contrato público de `searchPublicCatalog` ni el allowlist de tiendas. La clave permanece solo en el `.env` ignorado; `.env.example` queda vacío.

## Aceptación

- Prueba unitaria verifica que la URL Brave omite `country` y conserva idioma, consulta y límite.
- Smoke real de `carpas` con clave local sin imprimir secreto, respuesta 200 y resultados/páginas comprobados.
- `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run features:check` y CI verdes.
- Revisión independiente, handoff y PR lista para merge solo por el humano.
