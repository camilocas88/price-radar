# T-030 — Compatibilidad de región en Brave Search

- Dueño: Codex
- Estado: `done` (antes del merge humano)

- PR: https://github.com/camilocas88/price-radar/pull/22

## Objetivo y contrato

El smoke real con la clave local confirmó HTTP 422 (`VALIDATION`) al solicitar `country=CO`, y HTTP 200 con resultados de Éxito al omitir ese parámetro. El adaptador deja de enviar `country`, mantiene `search_lang=es` y la palabra «Colombia» en `q`. Además prioriza URLs de producto en vez de páginas de categoría: las primeras páginas de resultados de «carpas» eran categorías sin precio; al inspeccionar productos se verificó una oferta real de Éxito. No se cambia el contrato público de `searchPublicCatalog` ni el allowlist de tiendas. La clave permanece solo en el `.env` ignorado; `.env.example` queda vacío.

## Aceptación

- Prueba unitaria verifica que la URL Brave omite `country` y conserva idioma, consulta y límite; las categorías no consumen cupos de producto.
- Smoke real de `carpas` con clave local sin imprimir secreto, respuesta 200 y al menos un precio COP publicado.
- `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run features:check` y CI verdes.
- Revisión independiente, handoff y PR lista para merge solo por el humano.

## Handoff

- Comprobación de causa: Brave con `country=CO` devolvió HTTP 422 `VALIDATION`; la misma consulta sin `country` devolvió HTTP 200 y páginas de Éxito.
- Smoke de app local: `GET /api/offers?query=carpas` devolvió HTTP 200, una oferta publicada de Éxito (COP 219.900 en la consulta), cuatro enlaces sin precio verificable y estado 403 de Mercado Libre. No se mostró la clave.
- Gates: `npm run lint`, `npm run typecheck`, `npm test` (105 pruebas), `npm run build` y `npm run features:check` verdes. Revisión independiente `review_f023` sin bloqueantes.
- Archivos: solo `src/lib/public-catalog.ts`, sus pruebas y F-023/T-030. La modificación generada por `next dev` en `AGENTS.md` se retiró; `.env.example` no contiene la clave y `.env` continúa ignorado.
- Riesgo: el smoke comprobó un precio real de Éxito, no una comparación de precios entre varias tiendas. Falabella no publicó precio JSON-LD utilizable en las páginas consultadas; esas páginas se enlazan sin precio confirmado. Los patrones de URL podrían necesitar ajuste si una tienda cambia rutas.
