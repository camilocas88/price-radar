- Objetivo: que una búsqueda de texto muestre ofertas reales de Éxito y otras tiendas aun cuando Mercado Libre responda 403; Alkosto debe verse como fuente consultada, pero no aportar precios vencidos al ranking.

## Contrato previo a implementación

Se agrega un catálogo curado y pequeño de URLs de producto público, con cobertura declarada para iPhone 17/18 Pro Max 256 GB. No se consulta una página de resultados ni se descubre arbitrariamente toda la tienda. Cada URL está fijada en el código, pasa allowlist HTTPS, no sigue redirecciones, tiene límite de tiempo y bytes, y solo extrae JSON-LD `Product/Offer` o microdatos `itemprop` de producto/precio. Éxito puede publicar varios vendedores: cada precio utilizable conserva vendedor y fuente `exito`, sin llamarlo tienda oficial. El precio de Alkosto solo entra si `priceValidUntil` sigue vigente; si está vencido, se presenta en estado de revisión con enlace, nunca como oferta actual.

`GET /api/offers?query=` consulta Mercado Libre y las URLs curadas seleccionadas de forma independiente. Devuelve el contrato común `offers` validado, `needsReview`, `excludedCount` y `sources: {source,status,detail}[]`. Si Mercado Libre falla pero hay ofertas de otra fuente, responde 200 y el fallo de ML se muestra como estado parcial, no como error que borre las ofertas. Si no hay fuentes utilizables, no se presentan demos como reales. Se persisten solo ofertas actuales válidas cuando hay DB. La UI deja de atribuir todos los resultados a Mercado Libre y muestra estado por fuente.

El normalizador ignora `5G`/`5GB` como señal de conectividad y `12GB RAM` como memoria, para no confundir la capacidad de `256GB` del enlace de Éxito compartido. La condición no escrita en la consulta se interpreta como `nuevo` solo para este catálogo de productos nuevos y se informa en la respuesta/UI; no se mezclan usados con nuevos.

## Aceptación

- Prueba de 403 de Mercado Libre + JSON-LD válido de Éxito devuelve HTTP 200 con oferta real, fuente y vendedor correctos.
- Múltiples ofertas JSON-LD y microdatos se validan; precio vencido, moneda no COP, producto distinto y fallos/redirecciones quedan fuera del ranking.
- Búsqueda muestra fuentes parciales en lugar del mensaje global «fuente no disponible» cuando sí hay resultados.
- Catálogo limitado, timeout/bytes/no redirect, gates y CI verdes, revisión ajena y handoff.
