- Objetivo: permitir comparar ofertas de enlaces públicos aportados por el usuario aunque la búsqueda de Mercado Libre esté bloqueada, sin afirmar que un precio o inventario esté verificado.

## Contrato previo a módulos compartidos

`POST /api/compare-link` recibe `{ url: string }` y devuelve `{ url, store, title?, price?, currency?, extraction: "json_ld" | "manual", missingFields: ("title" | "price")[], notice? }`. El servidor acepta únicamente HTTPS, sin credenciales ni puertos personalizados, de dominios comerciales explícitamente permitidos; no sigue redirecciones, no hace login y no inspecciona HTML fuera de scripts `application/ld+json` con tipo `Product`. Limita tiempo y tamaño de respuesta. La extracción es informativa y siempre requiere confirmación del usuario antes de comparar. Si una página pública bloquea la consulta, devuelve un borrador `manual` para completar, no un error confundible con ausencia de ofertas. Una URL fuera de la lista devuelve 400 y no se consulta.

La UI conserva la búsqueda Mercado Libre y añade un comparador independiente de dos o más enlaces en la misma sesión. Permite completar título y precio en COP y muestra origen, URL y aviso de aporte no verificado. No inserta estos datos en `GET /api/offers`, no persiste ni marca precio, disponibilidad, envío o impuestos como confirmados. El precio comparado es el anunciado/aportado, no un total final; tampoco se infiere equivalencia de variantes sin revisión humana.

## Aceptación

- URL, dominio y esquema se validan antes de realizar la consulta; se bloquean redirecciones, hosts ajenos, credenciales, puertos y respuestas no HTML o excesivas.
- Solo se extraen campos de `Product` JSON-LD público; los faltantes se piden al usuario y toda oferta se etiqueta como aportada/no verificada.
- El usuario puede añadir al menos dos enlaces y ver sus precios COP ordenados, aun si Mercado Libre rechaza la búsqueda; no se inventan precio, envío o inventario.
- Pruebas de validación, extracción, degradación a manual, seguridad de fetch y comparación; lint, typecheck, test, build y features:check verdes; revisión ajena y handoff antes de `done`.
